# Ruri — registered portrait model

Extract the whole model folder into VTube Studio/Live2DModels. Reload the model list, choose Ruri, and run automatic parameter setup and camera calibration.

The neutral model reconstructs one canonical portrait without relocating its eyes, nose, mouth or bangs. Closed-eye and speaking edits are registered to that portrait; only local expression patches are blended. Head/neck/torso geometry shares continuous transforms. 11 authored parameters; small 2D turns only. No independent pupil tracking or editable cmo3.

Official Cubism Core and browser validation are separate from Steam VTube Studio testing. Steam VTube Studio itself has NOT been executed here.
