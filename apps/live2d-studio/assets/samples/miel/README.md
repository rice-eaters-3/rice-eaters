# Miel

Unzip the entire Miel folder into VTube Studio/Live2DModels, reload the model list, select Miel, and run automatic parameter setup and camera calibration. VTube Studio creates its own .vtube.json.

Actual binary MOC3, 13 rig parameters, 10 visible meshes. Closed-eye sprites replace flattened open-eye textures. The head illustration is kept cohesive, facial features share one transform, and the torso is anchored at the neck. Transparent atlas and project layout included.

Small 2D head turns only; no independent pupil tracking, hand rig or editable Cubism Editor .cmo3. This is an original AI-generated adult character reworked into a runtime puppet. Steam VTube Studio direct execution has NOT been tested. Consult validation.json for runtime evaluation results.
