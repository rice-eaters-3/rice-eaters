# Lumi — VTube Studio import

1. Extract this ZIP first. Copy the entire Lumi folder into VTube Studio/Live2DModels.
2. Restart VTube Studio or reload the model list, then select Lumi.
3. Use the VTube Studio auto-setup and camera calibration. The app creates its own .vtube.json configuration.
4. Eye blink, mouth opening and head/body angles use standard parameter IDs. Adjust tracking ranges in VTube Studio if necessary.

This is an automatically assembled draft with 16 image parts and 13 rig parameters. No independent pupil tracking, hand rig or editable .cmo3 project is included. project.json preserves layer placement for this web app. The .moc3 is a real binary runtime model, not a renamed image. Runtime validation does not replace testing in the Steam VTube Studio application.

The artwork was AI-generated. Review anatomy, layer seams and rights before public/commercial use.
