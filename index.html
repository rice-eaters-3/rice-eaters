A small project with a big appetite

rice-eaters 🍚

쌀을 먹는 자들. 대화로 아이디어를 다듬고, 코드를 고치고, 작지만 쓸모 있는 앱을 하나씩 만들어 가는 프로젝트입니다.

우리의 작업 방식

원하는 기능을 대화로 설명하면, 코드 변경 사항을 이 저장소에 반영합니다. 변경된 코드를 내 컴퓨터에서 실행하고 결과를 알려주면 다음 개선을 이어갑니다.

01 · 이야기하기만들고 싶은 기능이나 고치고 싶은 점을 말해 주세요.
02 · 코드 반영변경 내용을 검토하고 GitHub 커밋으로 관리합니다.
03 · 실행하고 개선로컬에서 확인한 결과를 바탕으로 다음 버전을 만듭니다.
